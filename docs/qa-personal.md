## 持久資料錯誤處理

- 正常保存先完成新資料序列化及 localStorage 寫入，成功才切換記憶體資料；quota 失敗不偽報成功。
- 初始 localStorage JSON 損壞／版本不支援時保留原始字串，顯示警告與原始復原檔下載，阻止一般寫入覆蓋。可還原有效 JSON 解除；復原檔應先另存。
- JSON 匯入先檢查整份資料，再合併與原子寫入。任何驗證或寫入失敗保留原資料。匯入相同時間戳以匯入版本優先。
- 分享使用欄位白名單；全備份是私人完整備份，不能視為公開分享檔。CSV 明示含私人備註，並轉義引號、換行和試算表公式前綴。
- 清除瀏覽器資料會移除個人資料；無後端自動復原。同步開啟多個分頁目前沒有跨分頁寫入鎖，應在單一分頁編輯並定期備份。
