## 安全與失敗狀態

- 來源文字透過 HTML escaping，外部連結限定 http/https、noopener noreferrer。編輯資料未載入時保持空資料，不捏造內容。
- 私人翻譯 URL 只有 `public === true` 才建立入口；但公開 JSON 內的私人 URL 本身仍公開，因此不能放入檔案。
- PDF iframe 仍受遠端 CSP／X-Frame-Options 限制，外部入口保留；尚未做失敗事件提示與具體瀏覽器驗收。
- editorial.json 下載失敗沒有獨立提示／重試，目前與尚未填資料無法區分，需改善。
- 全站文件任何一個分片失敗會整批失敗；畫面有重試方式，但沒有局部結果或失敗分片清單。
- 人物名以來源字串切割，需核對逗號、括號與姓名分隔的資料慣例，不能宣稱已解決同名與人物識別。
- 整合前必須確認事件只初始化一次、載入順序、行動裝置選取比較操作與鍵盤焦點。以上未經自動單元測試證明。

## 私人原譯文閱讀與版次樣本

BA-041/044/045：詳情提供兩個「從此裝置開啟原文／譯文PDF」輸入；使用者自行選擇檔案後，兩個iframe在寬螢幕並列、手機上下排列。只產生瀏覽器Blob URL，不上傳、不寫JSON、不持久化檔案或存取權；重整後需重選。副檔名、非空檔與 `%PDF-` 開頭均驗證；替換檔案釋放舊URL，切換詳情、關閉dialog及pagehide釋放所有URL。嵌入閱讀失敗保留同一Blob的新分頁入口。這不代表私人PDF已取得公開發布許可。

自動測試覆蓋兩側獨立、同側替換URL釋放、clear可重複、revision阻止切換詳情後的非同步舊選取結果、非PDF／偽裝PDF／空檔拒絕。瀏覽器驗收需兩側各選一份本機PDF，替換其中一側、切換遊戲及關閉重開確認不保留檔案；檢查網路沒有檔案上傳請求。
